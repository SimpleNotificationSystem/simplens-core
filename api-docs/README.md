## Usage of Bruno API Docs
- Make sure you have the `Bruno Desktop App` version >= 3.1.3
- Open this collection (`/api-docs` is the root) in your Bruno Desktop App
- Use the `.env` file method to load the env vaiables. 
    - Copy .env.example into .env and then fill the values
        ```bash
        cd api-docs
        cp .env.example .env
        ``` 
    - Then copy those values in .env into the `Bruno Desktop App` .env file
- Now you can run the requests

Refer the [Bruno Docs](https://docs.usebruno.com/secrets-management/dotenv-file#manage-environment-credentials) for more detailed info
